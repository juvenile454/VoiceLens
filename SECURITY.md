# Security policy

## Supported versions

| Version | Supported |
|---|---|
| 0.2.x | Yes |
| < 0.2 | No |

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting: <https://github.com/juvenile454/VoiceLens/security/advisories/new>.

Do not open a public issue for a security problem, and do not attach private recordings or transcripts to a report.
