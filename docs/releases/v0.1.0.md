# VoiceLens 0.1.0

An early source release of a native GTK 3 dictation app for Ubuntu 24.04 / GNOME 46 on x86_64. Hold Control, speak, and release to insert text at the caret, or use Record / Stop in the app.

## Included

- Local faster-whisper transcription with English and German interface and recognition settings.
- Automatic microphone and complete local-model discovery, with setup diagnostics and actionable error messages.
- GNOME Push-to-Talk, caret overlay and insertion into the focused application.
- Short-lived transcription workers, anonymous in-memory audio and no built-in transcript history.
- MIT-licensed source, installation instructions, offline model guidance and regression tests.

## Install

Extract the source archive into its final location and follow [the installation guide](../../README.md#install). Prepare a dedicated Python speech environment and one complete local CTranslate2 model, run `/usr/bin/python3 install.py --check`, then `/usr/bin/python3 install.py`.

The installer checks existing components and installs user launchers and the GNOME helper. It does not download packages or models. Model weights are linked upstream and are not included in the source archive. No subscription or cloud service is required.

## Validation and limits

In-app dictation and Control-hold dictation passed a manual smoke test on Ubuntu 24.04 / GNOME 46 / Wayland with a local Small model. Existing dependencies and model cache were reused. The final release identifier and runtime-discovery cleanup is covered by automated tests; a fresh-account installation of that final configuration still needs validation.

See [validation details](../release.md) for the tested runtime versions, automated checks and remaining hardware coverage. This is an early release with limited platform coverage. Windows, macOS and untested GNOME versions are not supported. Review transcription results before using them.

Source checksums apply to the attached VoiceLens source archive, not to external model files or Python packages. Model and dependency licenses remain separate from the application MIT license.
