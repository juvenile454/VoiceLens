# VoiceLens 0.2.0

A refresh of the native window and a few quality-of-life features for daily dictation. Recording, transcription and privacy behaviour are unchanged: audio stays in memory, nothing is downloaded, no history is written.

## Interface

- Reworked stylesheet: calmer surfaces with soft card shadows, a gradient Record / Stop button, styled microphone selector, scrollbars, switches and a header menu. The visualizer background now blends into the window.
- Colour-coded state: the phase line and status line carry a dot that is mint when ready, coral while recording, violet while working and amber when setup needs attention.
- Live microphone level bar under the microphone selector, and the recording budget next to the timer (the timer turns coral in the last minute).
- Transcript header shows word and character counts, a clear button and a copy button with a short "Copied ✓" confirmation.
- Settings dialog split into **General** (language, push-to-talk, post-transcription behaviour) and **Model** (installed / recommended chips, setup help, open models folder).
- Header menu with Settings, Setup help and a keyboard shortcut list.

## Features

- **Append to the transcript** (off by default): a new result is added below the existing text instead of replacing it.
- **Copy the text automatically** (off by default): each result is placed in the clipboard.
- **Escape** cancels the running recording or transcription and keeps the previous text; **Ctrl+Shift+C** copies the transcript.
- **Open models folder** creates and opens `~/.local/share/voicelens/models` in the file manager.
- **Model in memory** (Settings → Model): release after each take (default, unchanged behaviour), keep for a chosen number of minutes after the last use, or keep loaded (loaded at start-up). The footer shows the loaded model and the remaining time; the app menu offers *Load model now* and *Release model*. The resident worker is still a guarded child process that receives each recording as a passed memory descriptor and ends with the app.

## Compatibility

Settings files from 0.1.0 load unchanged; the new keys default to off / release. The worker gains a `--serve` mode used only by the resident option; the GNOME extension, the installer and the CLI are unchanged.

## Validation

Automated isolated tests (153, xvfb, explicit backend doubles) pass, including new cases for append mode, auto copy, clear, Escape, Ctrl+Shift+C, settings persistence and the resident worker (protocol, process lifecycle, policies, window integration). Synthetic screenshots were regenerated. A manual smoke test on a real GNOME 46 desktop with a microphone and a local model is still recommended before relying on the new behaviour.
